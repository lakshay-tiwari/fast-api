# FastAPI Backend

A simple FastAPI backend for learning and experimenting with FastAPI.

## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/lakshay-tiwari/fast-api.git
cd fast-api
```

### 2. Create a virtual environment

```bash
python -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirement.txt
```

### 4. Start the server

```bash
uvicorn main:app --reload
```

The API will be available at:

```text
http://localhost:8000
```

API docs: http://localhost:8000/docs
